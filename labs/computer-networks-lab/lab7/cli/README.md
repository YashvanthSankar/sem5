# Lab 7 CLI practice

Run `python3 server.py` in one terminal and `python3 client.py` in two
others. Join with two names (or type `random`), then choose `rock`, `paper`,
or `scissors`. Try `chat`, `replay`, and `exit`.

The CLI version uses the same commands and game rules as `../server.py`
and `../client.py`. The assessed question requires a GUI, so use the parent
files for that demonstration.
