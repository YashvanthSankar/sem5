## Q1 — Multiplayer socket game with GUI

Create a game of your choice that needs at least two players. Provide a
Python GUI and a client/server socket program.

- Ask for a username on connection. If taken, ask again. Offer a **random
  unused name generated by the server**.
- Show a chat box beside the game so players can message one another.
- Pair players in **FIFO order**: player 1 waits for player 2; player 3 waits
  for player 4; and so on. The game starts only when both players are ready.
- If a player leaves during a game, declare the remaining player the winner
  and end that game.
- After a game ends, offer **REPLAY** and **EXIT**.

Test your server with at least two friends as clients, and your client with
a friend's server and another client. Capture server GUI logs showing joins,
leaves, socket addresses, and session durations. Capture 3–4 client GUI
screenshots showing moves, chat, waiting, game result, replay, and exit.
Combine screenshots into one PDF with name and roll on every page. Put name
and roll comments in both programs; submit the PDF, `client.py`, and
`server.py` separately before the deadline.

## Q2 — DHCP in one and two LANs

**A. One LAN:** connect six end devices, a DHCP server named `IIITDM DHCP
Server`, and a static-IP HTTP web server to one switch. Use a Class C network.
The DHCP pool must begin at **192.168.1.12**. Show that every end device
receives an address dynamically and can open the hosted page by the web
server's IP. Observe DHCP packets and explain the server's role and benefits.

**B. Two LANs:** build L512 and L509, each with at least five devices and a
switch, joined by a router. Put the DHCP server on L512 with two pools:
L512 starts at **192.168.12.15**; L509 starts at **192.168.9.115**. Configure
`ip helper-address <DHCP-server-IP>` on the router interface facing the
remote L509 LAN. Verify dynamic addresses and ping within and across LANs.

Submit one combined `.pkz` and a PDF with comments, ping, realtime, and
Simulation-mode screenshots. Put name and roll in the Packet Tracer scene
before taking screenshots. Submit individually.
