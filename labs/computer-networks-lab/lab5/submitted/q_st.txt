Write a Single Server-Multiple Client program in which clients can communicate(chat) with other clients using GUI interface, with the following requirements:
•    Each client connection is handled in a separate thread on the server.
•   The client should send its username while it connects to the server. The server should return a success message if the username is available; otherwise, it should ask the client to choose a different username.
•    The client has the following functionalities:
         (i)   User List Button (/users) – the server will return a list of active users who are currently connected to the server.
         (ii)  Message Field and user id field (<user1>:msg) – the client wants to send a message msg to user1.
         (iii) Broadcast Button (<broadcast>:msg)  – the client wants to send a message to all users connected to the server except itself.
         (iv) Exit Button (/exit) – the client disconnects from the server.
•    The client should print the message received by it. It should mention the username.
•    The server should maintain a dynamic list of connected users in the format (socket:user_name). When the user disconnects, the entry should be removed from the current active users. Note that the username for a client is not fixed and can change when the user reconnects again.
•    The server provides four message functionalities when a user requests:
        (i)   /users: the server will send the list of active users (user names only) who are currently connected to the server.
        (ii)  <user1>:msg – the server forwards the message msg to user1. If user1 is not available or has disconnected from the server, an appropriate message (“User Not Online”) should be sent back to the client.
       (iii) <broadcast>:msg – the server broadcasts the message msg to all the active users except from which the request was received.
        (iv) /exit – the connection to the client is closed and its entry in the active users is removed.
•  The server displays the count and list of active client connections(both socket address and username) whenever a client connects or disconnects on its terminal.                      
•  The server maintains a log file (log.txt) recording
       (i)   Username conflicts
       (ii)  each user’s joining time (if no username conflict);
       (iii) leaving time and the session time after the user leaves.  
       (iv) Which user sent a message to which user, size of message and the status (send/failed with reason)            
  Sample:
     [2026-09-03 19:32:40] : 172.16.222.244:65214, Username: user1, Activity: joined
     [2026-09-03 19:33:32] : 172.16.222.245:45121, Username: user2, Activity: joined
     [2026-09-03 19:33:45] : 172.16.222.246:35210, AttemptedUsername: user1, Status: Rejected (Username already in use)
     [2026-09-03 19:34:40] : From: user1 (172.16.222.244:65214)), To: user2(172.16.222.245:45121), Size: 20Bytes, Status: Sent
     [2026-08-20 19:35:45] : 172.16.222.244:65214, Username: user1, Activity: left, session_duration: [00:03:05]
     [2026-09-03 19:36:10] : From: user2(172.16.222.245:45121),  To:user1 (172.16.222.244:65214), Size: 10Bytes, Status: Failed (User Not Online)
