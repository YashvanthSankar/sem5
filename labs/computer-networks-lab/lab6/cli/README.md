# Lab 6 CLI practice

Run `python3 server.py` in one terminal, then `python3 client.py` in two
other terminals. Log in with different names. Use `users`, `send`, and `exit`.
When sending, enter the receiver, full `.mp4` path, packet size, and delay.

This server is the same terminal server as `../server.py`. The CLI client
shows the file-transfer logic without Tkinter. For assessment, use the GUI
client in `../client.py`, which has the required controls and progress bars.
