# Lab 8 CLI practice

Run `python3 server.py` and then `python3 client.py` in separate terminals.
Enter a username, answer each question with A/B/C/D (or `-` to skip),
and try replay. The server alone checks the answers and sends the score.

The CLI version uses the same quiz protocol as the GUI files in `..`.
Use those GUI files for the assessed question, including Save Choice and
Reset Choice buttons.
