Q1.Write a Single Server-Multiple Client program for text file transfer using Python threading, with
the following requirements:
● Each client connection is handled in a separate thread on the server.
● When a client connects, the server assigns a unique username (e.g., user1, user2, user3, ...)
and immediately sends this username to the client. The username stays constant if the client
disconnects and then reconnects again in future.
● The client then sends the name of a text file it wants to upload.
● The server checks if a file named clientusername_<filename>.txt already exists on the server.
If the file already exists, the server immediately responds with the message "File already
exists" and rejects the file transfer. If the file does not exist, the server responds with
"READY" to signal that it is ready to receive the file content.
● Upon receiving "READY", the client reads the specified text file from its local system and
sends the file data in chunks to the server.
● To simulate realistic network conditions and demonstrate simultaneous multi-client
handling, the client introduces small delays (time.sleep()) between sending each chunk of
the file.
● The server receives the incoming data and writes it into a file named using the format
clientusername_<filename>.txt.
● After successfully receiving and saving the entire file, the server sends a confirmation
message "Upload Complete for clientusername_<filename>" back to the client indicating
successful receipt.
● The connection between client and server is terminated after the file transfer is completed.
● The server displays the count of active client connections whenever a client connects or
disconnects.
● The server maintains a log file (server_log.txt) recording every file transfer event with the
following details: Timestamp of the event, Client Socket Address, Assigned client username,
File name, Action taken by the server (Accepted or Rejected), Size of the file received (if
applicable)
Sample:
[2025-08-20 19:32:40] ServerSocket: 172.16.222.245:65214, ClientSocket:
192.168.2.173:12345, Username: user1, File: user1_cl1.txt, Action: Accepted, Size: 1354
bytes
[2025-08-20 19:33:32] ServerSocket: 172.16.222.245:65214, ClientSocket:
192.168.2.173:12345, Username: user1, File: user1_cl1.txt, Action: Rejected
● The client program should handle the server’s rejection gracefully, prompting the user to
either retry with a different file or exit the program.
