## Q1 — Linux networking commands

Explore these commands and commonly used options:

`ifconfig`, `ip`, `traceroute`, `tracepath`, `ping`, `netstat`, `ss`, `dig`,
`nslookup`, `host`, `arp`, `hostname`, `curl` or `wget`, `whois`, `iftop`.

For **each command**:

1. Run it with several commonly used options.
2. Take a clear terminal screenshot showing each command and its output.
3. Write a short note explaining the command's purpose and the options used.

Combine the screenshots and notes into **one PDF**. Put your name and roll
number on every page and submit individually.

## Q2 — Ethernet cables in Cisco Packet Tracer

Connect two computers and test all four cases:

| Cable | Computers' IP networks |
|---|---|
| Straight-through Ethernet | Same network |
| Straight-through Ethernet | Different networks |
| Crossover Ethernet | Same network |
| Crossover Ethernet | Different networks |

Also explain what a crossover Ethernet cable is and show its connection.
Explain what a CAT-6 cable is and what each wire colour represents.

Submit a PDF with comments and Packet Tracer screenshots. Show your name and
roll number in the topology **before** taking screenshots. Submit a ZIP
containing the `.pkz` file(s); the four cases may be separate or combined.
Submit individually.

The saved topologies are in [submitted/cpt-pkz-files](submitted/cpt-pkz-files/).
