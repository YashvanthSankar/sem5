CS3006 CLT Lab: Bernoulli and Binomial (offline version)
=========================================================

How to start
  1. Extract the whole zip file first.
       Windows: right-click the zip, choose "Extract All...".
       Mac:     double-click the zip.
     Do not open the HTML file from inside the zip preview.
  2. Open the extracted folder and double-click
       CS3006_CLT_Bernoulli_Binomial_Lab.html
     It opens in your browser (Chrome or Edge recommended).
  3. Wait for the green "Python ready" light at the top. This takes a few
     seconds the first time you open the page in each session.
  4. Work through modules 1 to 6. Press "How to use this lab" for the guide.

Things to know
  * No internet connection is needed. Python, NumPy, SciPy and matplotlib
    are inside the "lib" folder.
  * Keep the "lib" folder next to the HTML file. Do not move the HTML file
    out of its folder or delete "lib".
  * Your work is saved in your browser on this computer. Do not use a
    private or incognito window.
  * When you finish, press "Submit my work", enter your name and roll number,
    and download the .py file to upload.

If Python does not start
  * Check that you extracted the whole zip (not opened the HTML inside the zip).
  * Check that the "lib" folder is next to the HTML file.
  * Try Chrome or Edge. Copy the red message and send it to your instructor.
