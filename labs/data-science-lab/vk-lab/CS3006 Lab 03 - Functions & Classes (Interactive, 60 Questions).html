Section A · Functions I — scope, arguments & return (Q1–Q15)
Topics: local vs global · positional & keyword args · return semantics · references vs rebinding · immutability

Q1Short code
Write a function double(x) that returns x*2. Call it on 21 and print the result.
Q2Short code
A function with no explicit return returns None. Complete greet so it prints a greeting but returns nothing, then print the returned value to confirm it is None.
Q3Short code
Local names do not leak out. Inside f bind k = 99. Outside, k = 1 is already set. Print k after calling f() to show the outer k is unchanged.
Q4Short code
Use global to rebind a module-level name. Complete bump so it increases the global total by 10.
Q5Short code
Positional vs keyword arguments reach the same parameters. Define rate(score, out_of) returning the percentage as an int. Call it once positionally and once with keywords; print both.
Q6Short code
A function can return multiple values as a tuple. Complete min_max to return the smallest and largest of a list, then unpack into two names and print them space-separated.
Q7Short code
Passing a list passes a reference: mutating it inside the function is visible outside. Complete add_bonus to append 5 to the passed list, then print the caller's list.
Q8Short code
Rebinding a parameter to a new object does not affect the caller. Inside f, reassign xs to a new list. Show the caller's list is unchanged.
Q9Short code
Integers are immutable, so a plain x += 1 inside a function cannot change the caller's int. Print the caller's value after the call to show it stays 5.
Q10Short code
A function that returns another value based on a condition. Complete grade: return 'PASS' if score >= 40 else 'FAIL'. Print the result for 38.
Q11Short code
return stops the function immediately. Complete first_fail to return the first score below 40, or -1 if none. Print it for the given list.
Q12Short code
Nested calls: the inner call's return feeds the outer. Given sq and inc, print sq(inc(3)).
Q13Short code
A parameter and a global can share a name; the parameter wins inside. With global score = 100, calling show(7) should print 7 then the global 100 stays. Print score after the call.
Q14Short code
Return a computed dict from a function. Complete tally to return a dict mapping 'pass'/'fail' to counts for the given scores (pass if >=40). Print it.
Q15Short code
A function can call itself indirectly through a helper. Complete average using a helper total that sums a list. Print the integer average of the scores.

Section B · Functions II — defaults, *args, closures, recursion, lambda (Q16–Q30)
Topics: default-argument trap & fix · *args / **kwargs · unpacking · closures · recursion · lambda · map / filter / sorted · higher-order functions

Q16Short code
Default arguments are used when the caller omits them. Complete power(base, exp=2) returning base**exp. Print power(5) and power(5, 3).
Q17Short code
The mutable-default trap. A default list is created once and shared across calls. Run this as written to observe the shared list growing.
Q18Short code
The correct fix. Use None as the default and create a fresh list inside. Now each call starts empty.
Q19Short code
*args collects extra positional arguments into a tuple. Complete total to sum any number of arguments. Print total(1, 2, 3, 4).
Q20Short code
**kwargs collects keyword arguments into a dict. Complete describe to print each key=value on its own line, in the order given. Call with name='Asha', score=72.
Q21Short code
Unpack a list into positional arguments with *. Given add3(a, b, c) and a 3-element list, call it by unpacking.
Q22Short code
A closure remembers the enclosing variable. Complete make_adder(n) to return a function that adds n to its argument. Build add10 and print add10(5).
Q23Short code
Each closure keeps its own captured value. Build two adders and show they are independent.
Q24Short code
Recursion: a function calling itself with a smaller input. Complete fact(n) (factorial), base case n<=1 returns 1. Print fact(5).
Q25Short code
Recursive sum of a list. Complete rsum: empty list returns 0, else first element plus rsum of the rest. Print rsum of the scores.
Q26Short code
A lambda is a small anonymous function. Assign a lambda that squares its argument to sq and print sq(9).
Q27Short code
sorted with a key lambda. Sort the gradebook by score ascending and print the names in order.
Q28Short code
map applies a function to each item. Use a lambda with map to add 5 to every score, then print the resulting list.
Q29Short code
filter keeps items where the function returns True. Use a lambda with filter to keep only passing scores (>=40). Print the list.
Q30Short code
Higher-order: a function taking a function argument. Complete apply_twice(f, x) to return f(f(x)). Test with a lambda that adds 3, starting at 0.

Section C · Classes I — __init__, self, attributes (Q31–Q45)
Topics: self & methods · instance vs class attributes · class counters · attribute shadowing · mutable class-attribute gotcha · composition

Q31Short code
Define a class Student with __init__(self, name, score) storing both on the instance. Create one and print its name and score.
Q32Short code
self is the instance, inserted automatically. Student('Asha', 72) runs __init__(<new obj>, 'Asha', 72). Add a method passed() returning True if score >= 40. Print it.
Q33Short code
A method can use another method via self. Add label() that returns the name plus ' PASS' or ' FAIL' using passed(). Print it.
Q34Short code
Instance attributes are per-object. Create two students and change one's score; the other is unaffected. Print both scores.
Q35Short code
Class attributes are shared by all instances. Add a class attribute pass_mark = 40 and a method using it. Print the pass_mark via an instance.
Q36Short code
A class-level counter. Increment Student.count (not self.count) in __init__ so it tracks how many were created. Create three, print the count.
Q37Short code
Assigning self.x when a class attribute x exists creates an instance attribute that shadows the class one. Show the class attribute is still 40 after one instance overrides it.
Q38Short code
The mutable class-attribute gotcha. A shared list class attribute is mutated by .append through any instance. Show both instances see the same list.
Q39Short code
Methods can update instance state. Add add_bonus(self, b) that increases self.score by b. Apply +8 and print the score.
Q40Short code
An object can hold a list attribute. Complete Gradebook so add appends a score and average returns the integer mean. Print the average.
Q41Short code
Two different objects are not equal by default even with equal data. Create two students with identical values and print whether they are the same object with is.
Q42Short code
A default parameter in __init__. Give score a default of 0 so Student('New') works. Print name and score.
Q43Short code
Return a computed value from an instance. Add grade() returning 'A' if score>=80, 'B' if >=60, else 'C'. Print for 72.
Q44Short code
A method calling a temporary object's method inline: Student(30).passed() creates an object, calls the method, discards the object. Print the boolean.
Q45Short code
Build a list of objects and iterate. Create students from names/scores, then print each name of those who passed (>=40), one per line.

Q53Short code
