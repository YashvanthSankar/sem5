# Q1 — Top 5 IPs with HTTP 401/403 in access.log (grep pipeline)

You have a web server log file access.log where each line follows some format.
Write a command pipeline (use a set of commands) using grep and to extract all IP addresses that received a 401 or 403 HTTP status code.

Count how many times each such IP address appears.

Display the top 5 offending IP addresses in descending order of count, in the format.

*(The line format and the required output format were cut off in the question file. From your screenshot the lines look like
`203.0.113.5 - - [19/Aug/2026:10:24:01] "POST /login HTTP/1.1" 401 512`.)*

## Compile & run

```text
bash q1.sh            (run in the folder that has access.log)
```

## Expected output

*for the log in your screenshot*

```text
      4 203.0.113.5
      2 198.51.100.22
      1 172.16.5.3
      1 10.0.0.9
```

## Answers

Log line format: `203.0.113.5 - - [19/Aug/2026:10:24:01] "POST /login HTTP/1.1" 401 512` → `$1` = IP, `$8` = status, `$9` = bytes.

**What each stage does:**

```text
grep -E '"[^"]*" (401|403) '      keep lines whose status (the number right after the quoted request) is 401/403
grep -oE '^[0-9]+(\.[0-9]+){3}'   print only the IP at the start of the line
sort                              put equal IPs next to each other (uniq only merges ADJACENT lines)
uniq -c                           count each IP
sort -rn                          numeric, descending by count
head -5                           top 5
```

**Same result with awk instead of the two greps:**
`awk '$8 == 401 || $8 == 403 {print $1}' access.log | sort | uniq -c | sort -rn | head -5`

**If the format must be "IP count":** add `| awk '{print $2, $1}'` → `203.0.113.5 4`

**Trap to avoid:** `grep -E '401|403' access.log` alone also matches a line whose byte count or URL contains 401/403
(e.g. `"GET /about HTTP/1.1" 200 401`). Tested: it wrongly adds `1 192.168.1.11`. Always anchor to the status field.
