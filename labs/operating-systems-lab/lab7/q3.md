# Q3 — Implement getproccount() (20 marks)

[Open the exam solution](q3.c)

Lab 7, xv6-public (x86). Copied word for word from the lab sheet. Solution code: `q3.c`.

Implement a system call getproccount() that returns the number of entries in the xv6 process table whose state is
not UNUSED. Count EMBRYO, SLEEPING, RUNNABLE, RUNNING, and ZOMBIE states.

Tasks
1. Assign an unused system call number to getproccount().
2. Modify syscall.h, user.h, usys.S, syscall.c, and sysproc.c.
3. Implement a helper in proc.c that traverses the process table and counts non-UNUSED entries.
4. Declare the helper in defs.h for use by sysproc.c.
5. Use appropriate synchronization while traversing the process table.
6. Return the count to the calling user program.
7. Write and run a user-level test program that prints the count.
8. Extend the test with fork(): compare counts before and while the child exists, accounting for concurrent system activity.
9. Explain each changed file and draw the kernel/user execution flow.

Sample test program
```c
#include "types.h"
#include "user.h"

int main(void)
{
    int count = getproccount();
    printf(1, "Active processes: %d\n", count);
    exit();
}
```

## Expected demonstration

On a quiet xv6 instance, expect counts of 3 before fork, 4 before wait, and 3 after wait. The child counts whether it is still runnable or already a zombie. Only `wait()` reclaims its entry. Other concurrent process activity can change the counts.

Hold `ptable.lock` throughout the scan. This question counts every non-UNUSED entry, including EMBRYO and ZOMBIE. The leading underscore in `_getproccount_test` is used by the build. The shell command is `getproccount_test`.
