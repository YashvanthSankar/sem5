# Q3 — Distributed Matrix Multiplier Using Worker Processes

Concept: Parallel computation, non-overlapping memory partition access.

API: System V (shmget, shmat) or POSIX Shared Memory (shm_open, mmap) + fork() / waitpid().

Problem Statement:

Multiply two large N × N matrices (A and B) using K independent worker processes. The parent process allocates shared memory for
Matrix A, Matrix B, and the resulting Matrix C. The parent forks K children, assigning row slices of C to each worker.

The parent forks K worker child processes. Each child is assigned a distinct slice of rows of Matrix C to compute:

C[i][j] = Σ (k = 0 … N−1) A[i][k] · B[k][j]

Because each worker writes to a mutually exclusive row partition of Matrix C, computations can proceed concurrently without locks or semaphores.

The parent waits for all K children to terminate, verifies the product matrix C, and cleans up all shared memory resources.

Initialization & Verification:

- Initialize Matrix A with all elements set to 1.0.
- Initialize Matrix B as an Identity Matrix (B[i][j] = 1.0 if i == j, else 0.0).
- Verification Rule: Since C = A × I = A, every element in C should evaluate to 1.0.
- If every element in C equals 1.0, print: Verification: SUCCESS or Verification: FAILED

## Compile & run

```text
  gcc -Wall -o q3 q3.c
  ./q3        then type:  8 3
```

## Expected output

*worker order varies*

```text
  Enter N (matrix size) and K (workers): 8 3
  Worker 1 (PID 19915): rows 0 to 1 done
  Worker 2 (PID 19917): rows 2 to 4 done
  Worker 3 (PID 19918): rows 5 to 7 done
  All workers finished.
  Verification: SUCCESS

  1000 4  -> rows 0-249, 250-499, 500-749, 750-999, Verification: SUCCESS
  3 5     -> two workers print "no rows (K > N)", Verification: SUCCESS
  ipcs -m afterwards shows no leftover segments.
```

## Answers

**Viva points:**
- Row split: worker w gets rows [w*N/K, (w+1)*N/K). Covers every row exactly once, even when
  K does not divide N.
- No locks needed: every worker WRITES only its own rows of C; A and B are only read.
- Segments are created and attached BEFORE fork(), so children inherit the same attachments
  (same physical memory). Memory that is NOT shared (normal arrays) would be copied.
- IPC_PRIVATE is fine here because only this process and its children need the segments.
- Parent waits (waitpid) for all K children before checking C, then shmdt + shmctl(IPC_RMID).
- A x I = A, so every C element must be exactly 1.0 (exact compare is safe: 1.0*1.0 + 0s).
