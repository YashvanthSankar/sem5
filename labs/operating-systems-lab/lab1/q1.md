# Q1 — line / word / character count and longest line

Write a program that reads a text file and prints:
- Total number of lines
- Total number of words
- Total number of characters
- The longest line in the file

## Compile & run

```text
  gcc -Wall -o q1 q1.c
  ./q1 input.txt          (no argument -> reads input.txt)

Test file (5 lines, the last one has no '\n'):
  Operating systems lab one
  fork creates a new process
    pipes   carry bytes one way
  short
  last line has no newline
```

## Expected output

```text
  Lines: 5
  Words: 20
  Characters: 113
  Longest line:   pipes   carry bytes one way

Check with:  wc -l -w -c input.txt   ->   4  20  113
  wc -l prints 4 because it counts '\n' characters, and the last line has none.
  Words and characters match wc exactly (characters include the '\n's).
```
