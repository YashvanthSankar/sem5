# Q5 — 3 fork() calls, exactly 4 processes (1 parent + 3 children), print the tree

Use 3 fork() system calls to create 4 processes exactly and
print the process tree that contains the PID of parent process along with the 3 child processes.

## Compile & run

```text
  gcc -Wall -o q5 q5.c
  ./q5
```

## Expected output

*PIDs/order of children vary*

```text
  Parent: PID 12970
    |-- Child 2: PID 12977, PPID 12970
    |-- Child 1: PID 12976, PPID 12970
    |-- Child 3: PID 12979, PPID 12970

Optional check from another terminal while it runs (add sleep(5) in the children):
  pstree -p <parent pid>
```

## Answers

**Why exactly 4:** only the parent calls fork(); each child returns immediately, so it
never reaches the next fork(). 1 parent + 3 children = 4.
(Plain fork(); fork(); fork(); would give 8.)
