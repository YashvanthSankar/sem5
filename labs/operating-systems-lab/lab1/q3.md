# Q3 — fewer than 16 processes using 4 fork() calls, print each PID

Write a C program to create less than 16 processes using 4 fork() calls also display the PID of each process.

## Compile & run

```text
  gcc -Wall -o q3 q3.c
  ./q3
```

## Expected output

*12 lines; PIDs/order vary*

```text
  PID: 12925  PPID: 12920
  PID: 12932  PPID: 12930
  ... (12 lines in total)
  PID: 12912  PPID: 12639       <- original process
  ./q3 | wc -l   ->  12
```

## Answers

**Counting:**

```text
fork();                 1 -> 2
fork();                 2 -> 4
if (fork() == 0)        4 -> 8   (4 parents get >0, 4 new children get 0)
    fork();             only those 4 children fork: 8 + 4 = 12
```

12 < 16 = 2^4, because the 4th fork() is executed by only half of the processes.
