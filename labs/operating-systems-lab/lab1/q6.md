# Q6 — Folder1/Folder2 on Desktop, grep from Folder2, show the file

Create 2 directories named Folder1 and Folder2 on desktop. Inside Folder1,
create a text file containing the text INDIAN INSTITUTE OF INFORMATION TECHNOLOGY.
From Folder2 use the grep command to search for the pattern INDIAN in the file and then display the complete contents of the file.

## Compile & run

```text
bash q6.sh            (or type the commands one by one in a terminal)
```

## Expected output

```text
INDIAN INSTITUTE OF INFORMATION TECHNOLOGY      <- grep (INDIAN highlighted)
INDIAN INSTITUTE OF INFORMATION TECHNOLOGY      <- cat
```

## Answers

**Useful variants:**
- `grep -n "INDIAN" ../Folder1/file.txt` — show line numbers
- `grep -i "indian" ../Folder1/file.txt` — ignore case
- `grep -r "INDIAN" ..` — search every file under Desktop
