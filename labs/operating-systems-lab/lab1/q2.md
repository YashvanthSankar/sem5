# Q2 — exactly three fork() calls -> 8 processes, print each PID

Using exactly three fork() system calls, write a C program to create 8 processes also display the PID of each process.

## Compile & run

```text
  gcc -Wall -o q2 q2.c
  ./q2
```

## Expected output

*8 lines; PIDs and order change every run*

```text
  PID: 12880  PPID: 12878
  PID: 12886  PPID: 12870
  PID: 12884  PPID: 12876
  PID: 12885  PPID: 12882
  PID: 12878  PPID: 12870
  PID: 12882  PPID: 12876
  PID: 12876  PPID: 12870
  PID: 12870  PPID: 12639        <- original process (its parent is the shell)
  ./q2 | wc -l   ->  8
```

## Answers

**Why 8:** every fork() doubles the number of processes running the next line.
1 -> 2 -> 4 -> 8  (2^n processes, 2^n - 1 of them are children).

**Process tree (P = original):**

```text
P -- C1 -- C3 -- C7
|      \-- C5
|-- C2 -- C6
\-- C4
```
