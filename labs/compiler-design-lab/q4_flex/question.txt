Question 4 (Lab 4): Flex Lexical Analyzer

Write a flex program (saved with a .l extension) for a simple C-like language.

Part A - Basic Token Recognition
Recognize:
  - Keywords: int, float, char, if, else, while, return
  - Identifiers
  - Integer constants
  - Arithmetic operators: +, -, *, /, %
  - Relational operators: <, >, <=, >=, ==, !=
  - Assignment operator: =
  - Delimiters: (, ), {, }, ,, ;
  - Whitespace ignored; unrecognized characters -> INVALID.

Part B - Extending the Lexical Analyzer
Additionally recognize:
  - Floating-point constants (3.14, 25.50)
  - Single-line comments (//)
  - Multi-line comments (/* */)
  - String literals (" ")
  - Character constants (' ')
  - Square brackets [ ]
  - Comments and whitespace ignored.
